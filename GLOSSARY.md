# Glossary

- **Agent descriptor (agent card):** machine-readable description of an agent's identity, skills, endpoint and authentication.
- **Agent-to-agent protocol:** a protocol for agents to exchange tasks, messages and results.
- **MCP (Model Context Protocol):** protocol connecting AI applications to tools and data sources.
- **HTTP 402 payment flow:** pay-per-request pattern where a server answers `402 Payment Required` with terms and the client retries with a signed payment.
- **Facilitator:** third party that verifies and settles payments on behalf of a service.
- **Session key:** a temporary key accepted by a smart account only under a spending and scope policy.
- **Policy engine:** deterministic code outside the model that approves or blocks proposed actions.
- **Indirect prompt injection:** instructions embedded in content an agent reads, aimed at changing its behaviour.
- **Escrow:** funds held by a contract or third party until delivery conditions are met.
- **Verify-then-pay:** releasing payment only after an agreed tool checks the deliverable.
- **Sybil attack:** one entity controlling many identities to gain disproportionate influence.
- **EigenTrust:** algorithm computing global trust by propagating local trust from pre-trusted peers.
- **Wash trading:** transactions between one operator's own identities to fake volume or history.
- **Collusion:** coordination between agents against the market or third parties.
